# Монитор запусков YC и a16z Speedrun

Это готовый локальный MVP для задания Pond. Он раз в восемь часов читает официальный каталог YC, каталог **a16z Speedrun**, объявления в X через TwitterAPI.io и публично индексируемые посты LinkedIn через TinyFish Search. Новые или изменившиеся сигналы сохраняются в SQLite и при разрешённой отправке публикуются в Slack.

## Главное

- Speedrun принадлежит a16z, а не YC — бот показывает это явно.
- Обсуждение YC не считается заявлением основателя.
- Раннее личное объявление получает пометку `EARLY SIGNAL — not yet confirmed`.
- Первый рабочий запуск по умолчанию только создаёт базовую линию и не засыпает Slack старыми компаниями.
- Ключи, Slack-токен, LinkedIn cookies и пароли в базу не записываются.
- Если Slack временно недоступен, сигнал останется неотправленным и повторится в следующий цикл.

## Быстрая проверка без ключей

```powershell
$env:PYTHONPATH = "$PWD\src"
python -m yc_launch_monitor demo --json
```

Настройки перечислены в `.env.example`, полная инструкция — в `README.md`, подключение Pond — в `docs/POND_AGENT_SETUP.md`.
